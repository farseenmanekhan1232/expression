## What is Expression?

Expression is a pipeline for your thinking. It starts with the same distraction-free freewriting canvas you already love — unfiltered, unjudged, yours alone. But it doesn't stop there. When you're ready, Expression helps you shape that raw brain dump into something the world can read, without steamrolling what you meant to say.

**The pipeline:**
- **Freewrite** — The sacred space. No AI touches it unless you explicitly ask. Just you and the blank page.
- **Polish** — Understands your intent, not just your grammar. Shapes your thoughts into clarity without losing your voice. Always optional. Never automatic.
- **Ideas** — An inventory of your thinking. Not a graveyard for drafts — a living map of what you've been thinking about.
- **Publish/Export** — When a thought is ready, send it out into the world.

**The line we don't cross:** AI never touches the freewrite canvas unless you explicitly ask. That space stays clean. That's the rule.

---

## Why not just use Freewrite?

Freewrite is the capture tool. Expression is the full pipeline. If you just want to brain dump, Freewrite is perfect. If you want to turn those brain dumps into something shareable — blogs, tweets, essays, notes — Expression gives you the bridge.

## Development

### Prerequisites

- Node.js 18+
- npm or yarn
- Expo CLI

### Run Locally

```bash
# Install dependencies
npm install

# Start development server
npx expo start

# Run on iOS simulator
npm run ios

# Run on Android emulator
npm run android
```

| Technology | Purpose |

| React Native | Cross-platform mobile framework |
